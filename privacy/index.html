Privacy Policy

Last updated September 28, 2026

Summary

There are no user accounts. The site does not use advertising trackers or analytics scripts.

What stays on your device

Settings, exchange API keys and preferences you save are stored in your browser's local storage. Clearing site data or using the app's remove options deletes them.

What is sent to our backend

  • Market data requests to the app's backend, which fetches public exchange data on your behalf.
  • Balance checks and orders. When you connect a key or place a trade, the key is sent to the backend so it can sign the request. Per its documentation, the backend holds keys in memory for that single request and does not write them to disk, a database or logs.

Standard server and hosting logs (such as IP address and request time) may be kept by our hosting providers.

Third parties

Pages load fonts from Google Fonts, which receives your IP address. Market data and orders go to the exchanges you use, under their own privacy policies.

Security note

Browser storage is convenient, not a vault. Only enter keys on devices you trust, and never enable withdrawal permission.
