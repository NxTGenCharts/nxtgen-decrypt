A practical guide to what each part of the terminal does and how results are calculated.

Overview

The Overview page shows market status (exchanges connected, markets loaded, cycles checked, profitable opportunities, best opportunity and scanner state), a live ticker and market movers. Run Full Scan runs the triangular and cross-exchange scanners together. A scan also runs automatically when the page loads.

Supported exchanges

Bitget, Binance, Bybit, MEXC and Gate.io. Public market data for all five is fetched through the app's market-data backend, which returns one merged, briefly cached response. If that backend is unreachable, the app falls back to calling exchanges directly from your browser.

Triangular Arbitrage

Finds three-leg cycles on one exchange that start and end in the same anchor currency (USDT by default; USDC, BTC, ETH, BNB or all are available). Controls include exchange, anchor currency, taker fee per leg (default 0.10%), minimum profit filter, minimum 24h volume, number of results and a live-scan interval. By default the scan uses live bid/ask prices and subtracts your fee assumption. A "Theoretical (CLI-style)" option uses last price with no fee, which is not realistic and shows larger numbers.

The page also carries Triangular Autotrade (spot). It starts from the balance of the exchange account you connected on the API Keys page, simulates cycles by default, and places real orders only if you explicitly arm Real order execution.

Cross-Exchange

Compares the same asset across exchanges and lists the buy venue, sell venue, estimated final amount for your chosen notional, how long the gap has been open, liquidity level and net profit after the taker fee. Advanced filters cover minimum volume, liquidity, window, quote asset, per-exchange toggles and a Bitget deposit/withdraw confirmation filter.

Futures Engine

The Futures Engine runs Live/Demo trading with several strategies, and shows your account balance (total including floating PnL, margin in use and free margin) with a Live/Demo toggle. Paper and Backtest live on Utilities & Tools. Live and Demo trading run from your browser tab while it is open and place orders only after you connect keys with trading permission and explicitly start them. Paper and Backtest do not place orders.

Utilities & Tools

Paper trading and trading bots for testing ideas without risking capital.

API Keys

Add exchange API keys on the API Keys page. Connecting runs a read-only balance check through the verification proxy. Bitget additionally needs the API passphrase. Keys are stored in your browser's local storage on your device. For signing, they are sent to the proxy, which by its documentation holds them in memory for a single request and does not persist or log them.

Recommended key setup: enable only the permissions you need, never enable withdrawals, and use your exchange's IP allow-list where available. Exchange IP restrictions can block orders routed through a hosted proxy.

Limits

Displayed spreads and returns are estimates at the moment of a scan. Prices move, orders can slip and fees apply. Nothing here is financial advice.
